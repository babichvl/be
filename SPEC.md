## 1. Общее описание продукта

**Название:** GymBro  
**Тип:** Telegram-бот + Mini App (WebApp)  
**Цель:** помочь фитнес-тренерам вести клиентов, а клиентам — отслеживать прогресс.

**Ключевые отличия:**
- Умные триггеры удержания клиентов
- Голосовое создание программ тренировок через ИИ
- Публичный профиль тренера + реферальная система
- Простота для пользователей без технических навыков

**Платформа:** Telegram (бот + Mini App)  
**Язык:** русский и английский (по языку Telegram)  
**Масштаб MVP:** до 100 пользователей  
**Срок MVP:** 4 месяца от старта разработки

### Технологический стек
| Слой | Технология |
|------|-----------|
| Фронтенд | HTML / CSS / Vanilla JS (GitHub Pages) |
| Бэкенд | Python, aiogram 3.x (Replit) |
| База данных | Supabase (PostgreSQL + Realtime) |
| ИИ | Anthropic Claude |
| Голос | Whisper |
| Видео | Jitsi Meet |
| Календарь | Google Calendar API |

### Правила безопасности (для разработчика)
- Никогда не вставлять реальные токены и ключи в код
- Бэкенд: только `os.environ.get("BOT_TOKEN")` и т.д.
- Фронтенд: допустим только публичный `anon key` Supabase
- В коде фронтенда не должно быть слов `service_role`, `secret`, `bot_token`

## 2. Роли

| Роль | Описание |
|------|----------|
| **Тренер** | Управляет клиентами, расписанием, программами, триггерами |
| **Клиент** | Записывается на тренировки, выполняет программы, отслеживает прогресс |
| **Лид** | Взаимодействует через публичный профиль, может отправить заявку |
| **Администратор** | Доступ к метрикам продукта |

Регистрация — только через Telegram (Telegram Login). Email/пароль не нужен.

#### 3.2. Умные триггеры (вкладка «Клиенты» → «Сообщения»)
- [ ] 12 триггеров (список ниже)
- [ ] Карточки триггеров: иконка, название, условие, тумблер вкл/выкл
- [ ] Настройка триггера: бонус (скидка/баллы), текст сообщения
- [ ] Автоматическое срабатывание при наступлении события

- [ ] Журнал действий по триггерам

**Список 12 триггеров:**
1. День рождения клиента → поздравление + скидка 10%
2. Давно не посещал (14+ дней) → скидка 15% при возврате в 48ч
3. Заканчивается абонемент (1–2 тренировки) → скидка 20% + 50 баллов
4. Серия 5 тренировок → 100 баллов + запрос отзыва
5. Серия 10 тренировок → скидка 10% + 150 баллов
6. Серия 15 тренировок → скидка 15% + 150 баллов
7. Серия 20 тренировок → скидка 25% + 150 баллов
8. Снизил активность за неделю → мотивационное сообщение + мини-задача
9. Новый лид → уведомление тренеру + 50 баллов после первой тренировки
10. Пригласил друга → 200 баллов пригласившему, бесплатная тренировка + 100 баллов приглашённому
11. Оставил отзыв → 50 баллов
12. Неоплаченная тренировка → вежливое напоминание

**Результат этапа 3:** автоматические удержание клиентов, программы назначаются и выполняются.
